# Contributing to RoachSwap

First off, thank you for considering contributing to RoachSwap! The colony only grows stronger when we build together. 

## How to Contribute

### 1. Find an Issue
Check out our Issues tab. Look for issues labeled `good first issue` if you're new, or `help wanted`.

### 2. Fork and Clone
1. Fork the repository to your own GitHub account.
2. Clone the project to your local machine.

### 3. Create a Branch
Create a branch for your feature or bug fix:
```bash
git checkout -b feature/my-new-feature
```

### 4. Make Your Changes
Write your code. Keep the brutalist, satirical tone in mind if you are adding UI elements!

### 5. Commit and Push
```bash
git commit -m "Add some feature"
git push origin feature/my-new-feature
```

### 6. Submit a Pull Request
Open a Pull Request against the `main` branch. Fill out the PR template completely so the admins can review your code efficiently.

## Code of Conduct
By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md). We are satirical, but we are not toxic. Treat your fellow roaches with respect.
